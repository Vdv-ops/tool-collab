# Task Collaboration Tool       INTERN ID:CITS8444

## Project Description

A simple Task Collaboration Tool built using HTML, CSS, and JavaScript. It allows users to view team members, manage project tasks, and add new tasks dynamically.

## Features

* Team Members List
* Project Task List
* Add New Task
* Success Popup Message
* Simple and Responsive Design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the project.
2. Open `index.html` in any web browser.
3. Enter a task and click **Add Task**.
